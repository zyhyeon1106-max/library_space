# 학교도서관 공간 구성 사이트 v0.3

## 추가 사항
- 사서교사 관리자 화면: 학교 조건(학급, 학급별 학생 수, 면적, 예산, 구조, 장서, 열람석 등) 입력 및 Firestore 저장
- 5개 공간 영역 개략 면적 배분도와 설명용 ANT 연결망
- 설문 집계(기존 기능)와 설계안 JSON 출력

## 중요: 업데이트 절차
1. 반드시 **현재 운영 중인** `public/js/config.js`의 올바른 Firebase 설정값을 보존하여 v0.3 폴더에 복사하세요. 기존 설정 파일을 덮어쓰지 마세요.
2. 반드시 **현재 운영 중인** `firestore.rules`에서 관리자 UID를 확인하고 v0.3의 `REPLACE_WITH_ADMIN_UID`를 동일하게 교체하세요.
3. 현재 폴더에서 `firebase use libraryspace-354fe`를 실행하세요.
4. `firebase deploy --only hosting,firestore:rules` 실행 후 `Ctrl+Shift+R`로 새로고침하세요.
5. 관리자 로그인 → 설문 조회 → 학교 조건 저장 → 시안 만들기 순서로 테스트합니다.
6. GitHub 저장소에도 변경된 파일들을 올려야 GitHub 버전과 실제 배포 버전이 일치합니다.

## 한계
- '평면도'가 아닌 **개략적 면적 구성 블록**입니다. 구조를 형상화하거나 가구를 배치하는 기능은 아직 없습니다.
- 동선·출입구·기둥·접근성·안전·법령·시공비는 검증하지 않습니다.
- 선호 수집이 주관식이므로 키워드 출현을 참고하는 초기 가중치일 뿐 실제 요구도 및 인과 관계 확증이 아닙니다.
- 연결망은 관계 후보를 시각화한 것이며 칼롱의 번역 과정에 대한 실증 연구는 아닙니다.
- 실명 설문 수집에는 학교별 개인정보 수집 근거·고지·보관기간·접근권한 검토가 선행되어야 합니다.
